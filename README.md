# Python PDF Editor

A simple and lightweight PDF editor built with Python.

The goal of this project is to provide the most useful PDF tools in one easy-to-use application without unnecessary complexity.

## Features

- **Merge PDFs**  
  Combine multiple PDF files into a single document.

- **Split PDFs**  
  Split a PDF into multiple separate documents.

- **Remove Pages**  
  Select and delete unwanted pages from a PDF.

- **Extract Pages**  
  Extract selected pages and save them as a new PDF.

- **Organize PDF Pages**  
  Reorder, rotate, add, or remove pages.

- **Scan to PDF**  
  Convert scanned documents or images into PDF files.

## Goals

The main goals of this project are:

- Simple and intuitive user interface
- Fast PDF processing
- Local file processing
- No unnecessary features
- Easy to use
- Open source
